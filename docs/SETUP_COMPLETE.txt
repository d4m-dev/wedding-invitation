🎯 BƯỚC 1: Tạo Supabase Account (MIỄN PHÍ)
   
   • Vào: https://supabase.com
   • Đăng ký bằng GitHub account
   • Tạo project mới
   • Chọn region: Singapore hoặc Tokyo
   
🎯 BƯỚC 2: Setup Database
   
   • Mở SQL Editor trong Supabase
   • Copy SQL từ file SUPABASE_SETUP.md
   • Run SQL để tạo tables & functions
   
🎯 BƯỚC 3: Lấy API Credentials
   
   • Vào Settings → API
   • Copy 2 thứ:
     ✓ Project URL
     ✓ anon public key
   
🎯 BƯỚC 4: Cấu Hình metadata.js
   
   • Mở file public/metadata.js — file cấu hình DUY NHẤT
   • Sửa mục backend:
     - supabaseUrl     → URL của bạn (kết thúc bằng /rest/v1)
     - supabaseAnonKey → anon key của bạn
   • Không cần sửa public/index.html / dashboard.html / js
   
🎯 BƯỚC 5: Deploy
   
   • Chạy:
     git add .
     git commit -m "Configure Supabase credentials"
     git push
   
   • Đợi 2 phút GitHub Pages rebuild
   • Test: https://d4m-dev.github.io/wedding-invitation/
